账户“撤销”实现为本地断开：删除本地凭据、缓存、索引、操作记录和游标，停止后续同步；Microsoft 端应用授权需在微软账户管理页撤销。客户端 OAuth 由部署者的授权服务器提供，本服务承担资源服务的验签和访问控制。管理页面自动化目前采用 Node 的 DOM 夹具，真实浏览器与真实登录操作列入上线验收。

## 九项验收场景

1. **部署和远程接入：** 自动化覆盖 Rust 发布构建、镜像构建、容器启动/401、MCP 初始化与工具调用；VPS HTTPS 和目标客户端连接待执行。
2. **两个 Microsoft 账户：** 本地模拟覆盖 device flow、刷新、默认账户、隔离和撤销；真实两账户授权待执行。
3. **完整 CRUD 和属性：** 工具及 schema 已实现，模拟合约覆盖方法/路径/请求体；真实 Graph 日期、提醒、正文和重复语义待执行。
4. **搜索：** 合成数据覆盖中文正文/标题、跨清单/账户、混合查询及筛选；真实同步数据验收待执行。
5. **微软客户端变更同步：** 模拟覆盖后台使用的 Delta 流、墓碑及状态；手机操作到 MCP 查询的全链路待执行。
6. **重启与故障恢复：** SQLite 关闭/重开、独立进程锁、分页恢复、429/断流、410 重建均有回归；真实 refresh token 跨重启待执行。
7. **已写成功但响应丢失：** 三条测试让合成 Graph 先提交 POST/PATCH/DELETE，再截断 2xx 响应。POST 核对找到远端 ID，返回候选供人工辨认；PATCH（含清空日期）读回确认成功；DELETE 读回 404 确认成功。同键重试均验证写请求仍只有一次。重复任务完成后下一次任务的微软端行为待真实账户核验。
8. **撤销清理：** 本地数据库级联、索引清理、代际屏障和晚到登录结果回归已覆盖；真实后台任务与管理页联机流程待执行。
9. **性能记录：** 可复现探针记录启动、RSS、查询 p50/p95、零 Graph 缓存请求及完整 JSON-RPC 字节。规模为一个合成账户、一张清单、一万任务；实际 VPS 基线待测。

## 恢复流程中的明确选择

- 创建响应丢失时，按 title/displayName 寻找候选，逐页返回 next_cursor。相同标题可以属于不同任务，因此保留 unknown，交由调用者核对其他字段及身份；不会自行重发 POST。若决定创建新的操作，须使用新 operation_key。
- 更新和删除可由只读核对将账本置为 succeeded。已发送给 Graph 的请求可能在本地断开后完成；代际屏障阻止结果重新写回已移除账户。
- 大操作记录在数据库保留完整内容；恢复接口返回有界摘要及 `_truncated` 标记。正常工具响应限制为完整 JSON-RPC 1 MiB，请使用分页或缩小查询。
- 附件和批量工作流属于 M2，未包含在本次 M1 中。
